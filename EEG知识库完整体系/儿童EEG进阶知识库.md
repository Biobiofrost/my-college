## 1. 儿童EEG发育特点

### 1.1 脑电频率发育规律

| 年龄段 | 主导频率 | 特点 | 临床意义 |
|--------|----------|------|----------|
| 新生儿(0-1月) | 0.5-3Hz | 不连续、交替性 | 脑成熟度评估 |
| 婴儿(1-12月) | 3-5Hz | 逐渐连续 | 发育迟缓筛查 |
| 幼儿(1-3岁) | 5-7Hz | θ波主导 | 发育里程碑 |
| 学龄前(3-6岁) | 7-8Hz | α波出现 | 认知发育 |
| 学龄期(6-12岁) | 8-10Hz | α波主导 | 学习能力 |
| 青少年(12-18岁) | 10-12Hz | 成人型 | 脑成熟完成 |

### 1.2 脑波发育里程碑

**关键里程碑**：
```
出生：不连续、交替性EEG
3个月：出现睡眠纺锤波
6个月：出现枕叶α节律
12个月：后头部优势节律建立
3岁：α频率达到7-8Hz
6岁：α频率达到8-10Hz
10岁：接近成人型EEG
```

**发育评估指标**：
| 指标 | 计算方法 | 临床意义 |
|------|----------|----------|
| 后头部优势频率(PAF) | 枕叶α峰频率 | 脑成熟度 |
| θ/α比值 | θ功率/α功率 | 发育迟缓 |
| δ/α比值 | δ功率/α功率 | 脑损伤 |
| 背景连续性 | 间歇时间比例 | 新生儿成熟度 |

### 1.3 睡眠EEG发育特点

**睡眠分期发育**：
| 年龄 | 睡眠特点 | EEG特征 |
|------|----------|----------|
| 新生儿 | 活动安静睡眠 | 不连续、交替性 |
| 3-6月 | REM/NREM分化 | 睡眠纺锤波出现 |
| 6-12月 | 成熟睡眠结构 | K-复合波出现 |
| 2-5岁 | 睡眠周期成熟 | 成人型睡眠结构 |
| >5岁 | 稳定睡眠模式 | 成熟睡眠EEG |

**睡眠纺锤波发育**：
- 出现时间：3-6个月
- 频率变化：12-14Hz → 11-13Hz
- 数量变化：逐渐减少
- 临床意义：脑成熟度标志

## 2. 儿童常见疾病及EEG特征

### 2.1 癫痫及癫痫综合征

**儿童特有癫痫综合征**：

| 综合征 | 发病年龄 | EEG特征 | 预后 |
|--------|----------|----------|------|
| **West综合征** | 4-8月 | 高度失律 | 发育迟缓 |
| **Lennox-Gastaut** | 1-8岁 | 慢棘慢波 | 难治性 |
| **儿童失神癫痫** | 4-10岁 | 3Hz棘慢波 | 良性 |
| **BECTS** | 2-14岁 | 中央颞区棘波 | 良性 |
| **Panayiotopoulos** | 3-6岁 | 枕区棘波 | 良性 |

**高度失律(Hypsarrhythmia)**：
- 特征：高波幅、杂乱、多灶性棘波
- 出现：West综合征
- 年龄：4-8个月
- 意义：严重脑病

**3Hz棘慢波**：
- 特征：双侧同步、节律性
- 出现：儿童失神癫痫
- 年龄：4-10岁
- 意义：良性预后

### 2.2 发育障碍

**自闭症谱系障碍(ASD)**：
| EEG特征 | 发生率 | 临床意义 |
|----------|--------|----------|
| 异常率升高 | 30-60% | 非特异性 |
| 癫痫样放电 | 20-30% | 共病癫痫 |
| α功率降低 | 常见 | 认知异常 |
| 连接性异常 | 常见 | 网络异常 |

**注意缺陷多动障碍(ADHD)**：
| EEG特征 | 发生率 | 临床意义 |
|----------|--------|----------|
| θ/β比值升高 | 60-70% | 亚型标志 |
| α功率降低 | 常见 | 皮层抑制不足 |
| 慢波增多 | 常见 | 成熟延迟 |

**智力障碍(ID)**：
| EEG特征 | 发生率 | 临床意义 |
|----------|--------|----------|
| 背景异常 | 50-70% | 脑功能异常 |
| 癫痫样放电 | 30-50% | 共病癫痫 |
| 成熟延迟 | 常见 | 发育迟缓 |

### 2.3 脑瘫

**EEG特征**：
- 背景活动异常：慢波增多
- 局灶性异常：与运动障碍对应
- 癫痫样放电：50-70%共病
- 成熟延迟：与运动发育相关

### 2.4 新生儿脑病

**缺氧缺血性脑病(HIE)**：
| 分级 | EEG特征 | 预后 |
|------|----------|------|
| 轻度 | 轻度异常 | 良好 |
| 中度 | 爆发抑制 | 中等 |
| 重度 | 低电压/平坦 | 不良 |

**脑室内出血(IVH)**：
| 分级 | EEG特征 | 预后 |
|------|----------|------|
| I级 | 轻度异常 | 良好 |
| II级 | 局灶异常 | 中等 |
| III级 | 异常明显 | 不良 |
| IV级 | 严重异常 | 不良 |

## 3. 儿童EEG数据采集挑战

### 3.1 配合度问题

**常见问题**：
| 问题 | 年龄段 | 解决方案 |
|------|--------|----------|
| 哭闹 | <3岁 | 游戏化、家长陪伴 |
| 移动 | <6岁 | 短时记录、动画片 |
| 拒绝配合 | 3-10岁 | 游戏化、奖励 |
| 焦虑 | 所有年龄 | 熟悉环境、家长在场 |

**游戏化采集策略**：
```
1. 环境设计：卡通装饰、玩具
2. 互动游戏：脑电游戏、反馈训练
3. 家长参与：家长陪伴、安抚
4. 奖励机制：贴纸、小礼物
5. 短时多次：5-10分钟/次
```

### 3.2 电极放置

**儿童电极系统**：
| 系统 | 电极数 | 适用年龄 | 特点 |
|------|--------|----------|------|
| 10-20 | 19 | >3岁 | 标准系统 |
| 10-10 | 64 | >6岁 | 高密度 |
| 儿童帽 | 32-64 | 所有年龄 | 专用设计 |
| 干电极 | 8-32 | 所有年龄 | 快速放置 |

**新生儿电极**：
- 减少电极数：8-16个
- 使用小电极：减少不适
- 快速放置：<10分钟
- 特殊固定：防止脱落

### 3.3 数据质量控制

**儿童数据质量指标**：
| 指标 | 可接受标准 | 处理方法 |
|------|------------|----------|

def ica_for_children(raw, age_months):
    """儿童ICA处理"""
    # 调整成分数量
    if age_months < 12:
        n_components = 10  # 新生儿少
    elif age_months < 36:
        n_components = 15  # 婴儿
    else:
        n_components = 20  # 幼儿
    
    # 使用稳健ICA
    ica = ICA(n_components=n_components, 
              method='infomax',

    # 自动识别伪迹
    ica.fit(raw)
    
    # 儿童眼电成分特点：额叶权重更高
    eog_indices, eog_scores = ica.find_bads_eog(raw, 
                                                 ch_name='Fp1',
                                                 threshold=0.8)
    
    return ica, eog_indices
```

class PediatricEEGModel(nn.Module):
    """儿童EEG模型"""
    def __init__(self, n_channels, n_classes, age_embedding=True):
        super().__init__()
        
        # 年龄嵌入（重要！）
        if age_embedding:
            self.age_embed = nn.Embedding(18, 32)  # 0-17岁
        
        # 时序特征
        self.temporal = nn.LSTM(n_channels, 64, batch_first=True)
        
        # 空间特征
        self.spatial = nn.Conv1d(n_channels, 32, kernel_size=3)
        
        # 分类器
        self.classifier = nn.Linear(64 + 32, n_classes)
    
    def forward(self, x, age):
        # 年龄嵌入
        age_emb = self.age_embed(age)
        
        # 时序特征
        temporal_feat, _ = self.temporal(x)
        
        # 空间特征
        spatial_feat = self.spatial(x)
        
        # 融合
        combined = torch.cat([temporal_feat[:, -1, :], 
                             spatial_feat.mean(dim=-1)], dim=1)
        
        # 分类
        output = self.classifier(combined)
        
        return output
```

## 7. 临床应用指南

### 7.1 适应症

**儿童EEG检查适应症**：
| 适应症 | 优先级 | 检查类型 |
|--------|--------|----------|
| 癫痫发作 | 高 | 常规+长程 |
| 发育迟缓 | 中 | 常规EEG |
| 意识障碍 | 高 | 急诊EEG |
| 行为异常 | 中 | 常规EEG |
| 睡眠障碍 | 中 | 睡眠EEG |

### 7.2 报告规范

**儿童EEG报告要素**：
```
1. 基本信息：年龄、性别、临床诊断
2. 记录条件：清醒/睡眠、电极、时长
3. 背景活动：频率、波幅、对称性
4. 异常发现：类型、部位、频率
5. 睡眠结构：分期、纺锤波、K-复合波
6. 临床意义：与临床相关性
7. 建议：进一步检查、随访
```

### 7.3 年龄特异性判读

**判读要点**：
| 年龄段 | 关注点 | 正常标准 |

| 婴儿 | 发育里程碑 | 频率、波幅 |
| 幼儿 | 背景、异常 | α波出现 |

**常见误判**：
