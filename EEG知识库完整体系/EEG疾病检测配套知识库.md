## 2. 数据处理知识库

### 2.1 EEG数据特性

**基本特性**：
- 多通道：通常64-256个电极
- 时序性：连续采样，通常256-1024 Hz
- 频域特性：δ(0.5-4Hz), θ(4-8Hz), α(8-13Hz), β(13-30Hz), γ(30-100Hz)
- 非平稳性：统计特性随时间变化
- 低信噪比：包含大量噪声和伪迹

**常见伪迹类型**：
| 伪迹类型 | 频率范围 | 来源 | 处理方法 |
|----------|----------|------|----------|
| 眼电(EOG) | 0.1-10Hz | 眨眼、眼动 | ICA、回归 |
| 肌电(EMG) | 20-500Hz | 肌肉活动 | 滤波、ICA |
| 心电(ECG) | 0.05-100Hz | 心跳 | ICA、模板匹配 |
| 工频干扰 | 50/60Hz | 电源 | 陷波滤波 |
| 电极噪声 | 宽频 | 接触不良 | 重参考、插值 |

### 2.2 预处理流程

**标准流程**：
```
原始数据 → 滤波 → 重参考 → 分段 → 去伪迹 → 特征提取
```

**详细步骤**：

**1. 滤波**
- 带通滤波：0.5-40Hz（根据任务调整）
- 陷波滤波：50Hz或60Hz（去除工频干扰）
- 工具：MNE-Python, EEGLAB

**2. 重参考**
- 平均参考：所有电极平均
- 拉普拉斯参考：局部平均
- 目的：减少参考电极影响

**3. 分段(Epoching)**
- 根据事件标记分段
- 去除基线：分段前100-200ms
- 去除坏段：阈值法、统计法

**4. 去伪迹**
- **ICA（独立成分分析）**：最常用
  - 分离独立成分
  - 识别伪迹成分（眼电、肌电等）
  - 去除伪迹成分
  - 重建信号
- **回归法**：用参考通道回归
- **小波去噪**：时频域去噪

**5. 特征提取**
- 时域特征：均值、方差、峰值等
- 频域特征：功率谱、频带能量
- 时频特征：小波变换、STFT
- 空间特征：协方差矩阵、连接性

## 3. 模型训练知识库

### 3.1 训练基础

**损失函数**：
| 损失函数 | 用途 | 特点 |
|----------|------|------|
| CrossEntropy | 分类 | 最常用 |
| BCELoss | 二分类 | 多标签分类 |
| Focal Loss | 不平衡数据 | 关注难样本 |
| Contrastive Loss | 对比学习 | 学习表示 |
| Triplet Loss | 度量学习 | 拉近正样本 |

**优化器**：
| 优化器 | 特点 | 适用场景 |
|--------|------|----------|
| SGD | 稳定、泛化好 | 通用 |
| Adam | 快速收敛 | 通用 |
| AdamW | 权重衰减 | Transformer |
| LAMB | 大batch训练 | 大规模训练 |

**学习率调度**：
| 策略 | 特点 | 适用场景 |
|------|------|----------|
| StepLR | 阶梯下降 | 简单任务 |
| CosineAnnealing | 余弦退火 | 通用 |
| OneCycleLR | 一个周期 | 快速训练 |
| ReduceLROnPlateau | 自适应 | 验证集监控 |

### 3.2 训练技巧

**正则化**：
- Dropout：随机丢弃神经元
- Weight Decay：权重衰减
- Batch Normalization：批归一化
- Layer Normalization：层归一化

**数据增强**：
- Mixup：混合样本
- Cutout：随机遮挡
- CutMix：混合+遮挡

**早停(Early Stopping)**：
- 监控验证集损失
- 连续N个epoch不下降则停止
- 保存最佳模型

**梯度裁剪**：
- 防止梯度爆炸
- 通常设置为1.0或5.0

### 3.3 评估指标

**分类任务**：
| 指标 | 公式 | 特点 |
|------|------|------|
| Accuracy | 正确数/总数 | 简单直观 |
| Precision | TP/(TP+FP) | 查准率 |
| Recall | TP/(TP+FN) | 查全率 |
| F1 Score | 2×P×R/(P+R) | 平衡指标 |
| AUC-ROC | ROC曲线下面积 | 不平衡数据 |
| Cohen's Kappa | 一致性 | 多分类 |

**回归任务**：
| 指标 | 公式 | 特点 |
|------|------|------|
| MSE | 均方误差 | 常用 |
| RMSE | 均方根误差 | 可解释 |
| MAE | 平均绝对误差 | 鲁棒 |
| R² | 决定系数 | 解释方差 |

### 3.4 交叉验证

**K折交叉验证**：
- 数据分为K折
- 每次用K-1折训练，1折验证
- 重复K次，取平均

**留一法(LOO)**：
- 每次留一个样本验证
- 适合小数据集

**时间序列交叉验证**：
- 按时间顺序划分
- 避免未来信息泄露

### 3.5 超参数调优

**方法**：
| 方法 | 特点 | 适用场景 |
|------|------|----------|
| Grid Search | 网格搜索 | 参数少 |
| Random Search | 随机搜索 | 参数多 |
| Bayesian Optimization | 贝叶斯优化 | 高效 |
| Hyperband | 早停策略 | 大规模 |

**关键超参数**：
- 学习率
- Batch Size
- 网络深度/宽度
- Dropout率
- 权重衰减

### 3.6 训练监控

**可视化工具**：
- TensorBoard：实时监控
- Weights & Biases：实验管理
- MLflow：实验追踪

**监控指标**：
- 训练/验证损失
- 训练/验证准确率
- 学习率变化
- 梯度分布
